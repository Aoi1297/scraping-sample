# スクレイピングツール（見本）

Webサイトの商品一覧を自動で集めて、**CSV と Excel に書き出す** Python ツールです。
「毎回ブラウザで開いてコピペしている」作業を、コマンド1つにまとめる例として作りました。

対象サイトは、スクレイピングの練習用に公開されている [Books to Scrape](https://books.toscrape.com/) です。

## できること

- 全50ページ（1000件）の商品を自動で巡回して取得
- タイトル・価格・評価・在庫・URL を一覧に
- `--detail` を付けると、詳細ページからカテゴリ・在庫数・商品説明も取得
- **CSV**（Excel で開いても文字化けしない形式）と **Excel**（見出し固定・フィルター付き）で保存

## 使い方

```
pip install requests beautifulsoup4 openpyxl
python scrape_books.py --pages 3            # 最初の3ページ
python scrape_books.py --detail             # 全ページ＋詳細
python scrape_books.py --out 2026-11-20     # ファイル名を指定
```

実行例：

```
16:26:28 ページ 1: 20件 (合計 20件)
16:26:49 ページ 2: 20件 (合計 40件)
16:26:49 保存しました: sample_output.csv / sample_output.xlsx (40件)
```

出力例は [sample_output.csv](sample_output.csv) / [sample_output.xlsx](sample_output.xlsx) にあります。

## 工夫している点

| 点 | 内容 |
|---|---|
| 相手のサイトに負担をかけない | アクセスの間隔を空ける（初期値1秒・変更可） |
| 止まりにくい | 通信に失敗したら、少し待って最大3回やり直す |
| 次のページを自動で判定 | 「次へ」のリンクがなくなるまで巡回 |
| そのまま使える出力 | 価格は数値に、評価は星の数（1〜5）に変換 |

## ご依頼に合わせて変えられること

- 対象サイト・取得する項目の変更
- 毎日決まった時間に自動実行（Windows のタスクスケジューラー等）
- Googleスプレッドシートへの書き込み、新着だけを Discord / Slack に通知
- 取得結果の集計・グラフ化

※ 実際のご依頼では、対象サイトの利用規約と robots.txt を確認し、許可されている範囲で行います。
